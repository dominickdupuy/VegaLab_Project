The workflow strip
A guided walk-through runs in a strip under the header, never over the page. It names the step, rings the control to use with Show me, and keeps Next locked until the step is actually done. Leave with × at any time; your runs stay.
Info tips
An ⓘ next to a term explains it in a sentence: vol points, seeds, power, the floor. Hover or tap it.
Settings live in the address
Change a control and the address changes with it. Reload, go back or share the link and the view is the same.
Runs name their code
Every run records the commit, the config hash and the seed that made it, under Provenance on the Runs page, and can be replayed from that record.
Exports
Each figure has an export bar, so a number in your notes can be traced to the view it came from.

3. Your first ten minutes

The guided question Real edge, or luck?, step by step, so you know what is coming. It launches two real runs, which take a minute or two each.

  1. Check the server status dot in the header is green. If it is red, start the server with make serve and reload.
  2. Press Start the first session below. The workflow strip appears under the header and opens the Launch page.
  3. Launch the fixed-delta seller in a fair-priced world: no premium, so it should make nothing on average. Wait for the run to finish; Next unlocks by itself.
  4. Launch it again with the “Planted 1 vol pt” quick start: now the options are dear by one vol point.
  5. On Runs, compare the two on the same market paths. The strip reads the difference out to you, with its uncertainty.
  6. On the Power lab, raise the seeds until a quarter of a vol point is caught 80% of the time. That is the size of test a learned strategy needs.
  7. Press Finish. You have now run the study's core comparison yourself; the Workbench's other questions follow the same pattern.
